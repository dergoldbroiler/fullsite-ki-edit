# Design-Tokens

Quelle: [Buhl Marketing Component Library](figma.md), gelesen an den Button- und Welcome-Frames.

## Farbe

| Token (Figma) | Wert | Verwendung |
| --- | --- | --- |
| `surface/primary/base` | `#023e84` | Primary-Button, Text, Rahmen Secondary |
| `surface/primary/bold` | `#011e42` | Primary Hover |
| (Welcome-Gradient) | `#0554b1` → `#023e84` | Hero-Kasten |
| `surface/primary/base-inversed` | `#ffffff` | Button-Text Primary, Karten |
| `surface/secondary/base` | `#ffe620` | Inverse Primary (nicht auf der Landingpage) |
| Hover-Flächen | `#f2f5f9` | Seitenhintergrund, Secondary Hover |
| `on-surface/text/primary/base-inversed` | `#ffffff` | Text auf Primary |

Body-Muted (`#4d6f9c`) ist aus Primary abgeleitet — Figma liefert für `text/primary/muted` keinen Hex am gelesenen Node.
